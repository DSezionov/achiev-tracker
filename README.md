# Трекер досягнень

Особистий веб-застосунок для відстеження досягнень у відеоіграх. Гру, розділи й досягнення ви заносите вручну (наприклад, з гайду в Steam), а потім відмічаєте отримані. Прогрес видно по кожному розділу, грі й загалом.

Статичний сайт для GitHub Pages: vanilla HTML, CSS і JavaScript (ES modules), без збирача і залежностей.

## Можливості

- **Головна:** загальний прогрес, коротка статистика, пошук ігор, фільтр за статусом (граю / пройдено / відкладено / покинуто), сортування (ручний порядок ↑↓, за назвою, за прогресом), бейдж «N пропускних», архів.
- **Сторінка гри:**
  - розділи, які можна згортати (усі разом теж), опція «ховати закриті розділи»;
  - великі чекбокси, дата отримання, sticky progress bar, фільтри та пошук (ігнорує регістр і розділові знаки, шукає й у назвах розділів та нотатках);
  - **лічильники** для «гриндових» досягнень (−/+ або точне значення);
  - **«Скасувати»** після кожної відмітки;
  - **спойлери**: умова й порада приховані до натискання;
  - **фокус-список «Зараз роблю»** (зірочка);
  - **точки неповернення**: попередження, якщо лишились пропускні;
  - **особисті нотатки** до досягнень;
  - підсумки гри (перше й останнє досягнення, за скільки днів 100%), конфеті при 100%, вібрація на Android.
- **Редактор:** поля гри зі статусом і архівом, обкладинка зі Steam, розділи й досягнення (↑↓, перенесення, видалення зі «Скасувати»), масові дії з вибраними, швидке додавання через Enter, масовий імпорт (свій формат, текст зі сторінки Steam, JSON), шаблон гри для обміну. Зміни зберігаються автоматично.
- **Статистика** (`#/stats`): ключові показники й серії днів, календар активності за пів року, графік за місяцями з таблицею, підсумки по іграх.
- **Налаштування:** тема, експорт та імпорт JSON («Замінити все» / «Додати ігри»), резервна копія, синхронізація через GitHub Gist, скидання прогресу гри, видалення всіх даних.
- **PWA:** можна встановити на телефон і користуватися офлайн.

## Запуск локально

```bash
python3 -m http.server 8000
```

Відкрийте http://localhost:8000. ES-модулі не працюють через `file://`, тому потрібен локальний сервер.

## Публікація на GitHub Pages

1. Запуште репозиторій у гілку `main`.
2. **Settings → Pages → Build and deployment**: Source «Deploy from a branch», гілка `main`, папка `/ (root)`.
3. Сайт буде доступний за адресою `https://<user>.github.io/<repo>/`.

Усі шляхи відносні, `.nojekyll` вимикає Jekyll.

## Масовий текстовий імпорт

```
## Сюжет
Новий старий друг | Пройти Кордон і поговорити з Сидоровичем.
! Посмішка Марти | Врятувати напарника-долгівця | Петра вбивай лише після нагороди.
? Серце Зони | Дійти до фіналу
## Колекціонування
Сталкерстрайк | Убити 50 сталкерів хедшотами. | | 50
```

- `## Назва` — новий розділ. Якщо розділ із такою назвою вже є, досягнення допишуться в нього.
- `Назва | Умова | Порада`. Порада необов'язкова.
- `!` на початку рядка — «можна пропустити», `?` — спойлер (можна разом: `!?`).
- Четверта колонка-число — ціль лічильника.
- Рядки до першого `##` потрапляють у перший розділ гри.

**Текст зі Steam.** Режим «Текст зі Steam» розбирає список, скопійований зі сторінки досягнень гри (глобальна статистика або особиста сторінка): назви й описи, `Unlocked …` позначає досягнення отриманим з датою, `23 / 50` стає лічильником.

Також можна вставити JSON однієї гри або шаблон, яким з вами поділились («Поділитися шаблоном» у редакторі). На сторінці «Нова гра» шаблон можна завантажити й за посиланням (наприклад, raw-файл публічного Gist).

## Синхронізація між пристроями

1. Створіть [Personal Access Token (classic)](https://github.com/settings/tokens/new?scopes=gist&description=achievement-tracker) лише з правом `gist`.
2. У «Налаштуваннях» вставте токен і натисніть «Підключити». Застосунок створить секретний Gist `achievement-tracker-data` з файлом `achievements.json`.
3. На другому пристрої вставте той самий токен: Gist знайдеться автоматично (або вкажіть його ID).

Як це працює:
- Токен зберігається лише в localStorage браузера.
- Під час відкриття сторінки, повернення у вкладку і раз на дві хвилини локальні дані **об'єднуються** з даними в Gist: зміни з обох пристроїв зберігаються на рівні окремих досягнень, видалене лишається видаленим.
- Зміни відправляються через 2 секунди після останньої дії, а якщо вкладку ховають (наприклад, блокуєте телефон) — одразу.
- Перед кожним оновленням даних з Gist попередня локальна версія зберігається в резервну копію (її можна відновити в «Налаштуваннях»).

## Структура

```
index.html            сторінка, шапка, підключення модулів
manifest.webmanifest  PWA
sw.js                 service worker (офлайн; «спочатку мережа» з тайм-аутом 3 с)
css/tokens.css        кольори, відступи, радіуси, шрифти (темна і світла теми)
css/styles.css        стилі компонентів
js/app.js             роутер (#/, #/game/<id>, #/game/<id>/edit, #/settings, #/stats), шапка
js/store.js           стан, localStorage, міграції, підрахунок прогресу, об'єднання станів
js/ui.js              іконки, progress bar, діалоги, сповіщення, тема
js/utils.js           uid, formatDate, escapeHtml, debounce, el та інше
js/import.js          розбір JSON і текстового імпорту
js/sync-gist.js       синхронізація з GitHub Gist
js/views/*.js         екрани
data/example.json     приклад даних
icons/                іконки застосунку
```

## Сховище в браузері

| Ключ localStorage | Вміст |
| --- | --- |
| `achievement-tracker:v1` | дані (ігри й прогрес) |
| `achievement-tracker:backup` | остання резервна копія |
| `achievement-tracker:prefs` | тема, сортування, фільтр статусу, згорнуті розділи (не синхронізуються) |
| `achievement-tracker:gist` | токен і ID Gist |
