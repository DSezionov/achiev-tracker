# Трекер досягнень

Особистий веб-застосунок для відстеження досягнень у відеоіграх. Гру, розділи й досягнення ви заносите вручну (наприклад, з гайду в Steam), а потім відмічаєте отримані. Прогрес видно по кожному розділу, грі й загалом.

Статичний сайт для GitHub Pages: vanilla HTML, CSS і JavaScript (ES modules), без збирача і залежностей.

## Можливості

- Головна: загальний прогрес, статистика (останнє отримане досягнення, кількість за тиждень і місяць), картки ігор, сортування (ручний порядок зі стрілками ↑↓, за назвою, за прогресом).
- Сторінка гри: розділи, які можна згортати, великі чекбокси, бейдж «Можна пропустити», розгортна порада, дата отримання, sticky progress bar, фільтри та пошук, повідомлення про 100%.
- Редактор: поля гри, розділи й досягнення (додати, змінити, видалити, ↑↓, перенести в інший розділ), швидке додавання через Enter, масовий текстовий імпорт із попереднім переглядом, JSON однієї гри. Зміни зберігаються автоматично.
- Налаштування: темна чи світла тема, експорт та імпорт JSON («Замінити все» / «Додати ігри»), резервна копія, синхронізація через GitHub Gist, скидання прогресу гри, видалення всіх даних.
- PWA: можна встановити на телефон і користуватися офлайн.

## Запуск локально

```bash
python3 -m http.server 8000
```

Відкрийте http://localhost:8000. ES-модулі не працюють через `file://`, тому потрібен локальний сервер.

## Публікація на GitHub Pages

1. Запуште репозиторій у гілку `main`.
2. **Settings → Pages → Build and deployment**: Source «Deploy from a branch», гілка `main`, папка `/ (root)`.
3. Сайт буде доступний за адресою `https://<user>.github.io/<repo>/`.

Усі шляхи відносні, `.nojekyll` вимикає Jekyll.

## Масовий текстовий імпорт

```
## Сюжет
Новий старий друг | Пройти Кордон і поговорити з Сидоровичем.
! Посмішка Марти | Врятувати напарника-долгівця | Петра вбивай лише після нагороди.
## Колекціонування
Сталкерстрайк | Убити 50 сталкерів хедшотами.
```

- `## Назва` — новий розділ. Якщо розділ із такою назвою вже є, досягнення допишуться в нього.
- `Назва | Умова | Порада`. Порада необов'язкова.
- `!` на початку рядка — «можна пропустити».
- Рядки до першого `##` потрапляють у перший розділ гри.

Також можна вставити JSON однієї гри (див. `data/example.json`; `id`, `done` і `doneAt` необов'язкові).

## Синхронізація між пристроями

1. Створіть [Personal Access Token (classic)](https://github.com/settings/tokens/new?scopes=gist&description=achievement-tracker) лише з правом `gist`.
2. У «Налаштуваннях» вставте токен і натисніть «Підключити». Застосунок створить секретний Gist `achievement-tracker-data` з файлом `achievements.json`.
3. На другому пристрої вставте той самий токен: Gist знайдеться автоматично (або вкажіть його ID).

Як це працює:
- Токен зберігається лише в localStorage браузера.
- Під час відкриття сторінки, повернення у вкладку і раз на дві хвилини застосунок звіряє `updatedAt`: новіші дані перемагають.
- Зміни відправляються через 2 секунди після останньої дії.
- Перед кожним перезаписом даних з Gist попередня локальна версія зберігається в резервну копію (її можна відновити в «Налаштуваннях»). Якщо дані змінювались на двох пристроях одночасно, лишається новіша версія, а інша потрапляє в резервну копію.

## Структура

```
index.html            сторінка, шапка, підключення модулів
manifest.webmanifest  PWA
sw.js                 service worker (офлайн, «спочатку мережа»)
css/tokens.css        кольори, відступи, радіуси, шрифти (темна і світла теми)
css/styles.css        стилі компонентів
js/app.js             роутер (#/, #/game/<id>, #/game/<id>/edit, #/settings), шапка
js/store.js           стан, localStorage, міграції, підрахунок прогресу
js/ui.js              іконки, progress bar, діалоги, сповіщення, тема
js/utils.js           uid, formatDate, escapeHtml, debounce, el та інше
js/import.js          розбір JSON і текстового імпорту
js/sync-gist.js       синхронізація з GitHub Gist
js/views/*.js         екрани
data/example.json     приклад даних
icons/                іконки застосунку
```

## Сховище в браузері

| Ключ localStorage | Вміст |
| --- | --- |
| `achievement-tracker:v1` | дані (ігри й прогрес) |
| `achievement-tracker:backup` | остання резервна копія |
| `achievement-tracker:prefs` | тема, сортування, згорнуті розділи (не синхронізуються) |
| `achievement-tracker:gist` | токен і ID Gist |
